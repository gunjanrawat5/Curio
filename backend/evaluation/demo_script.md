# TeachBack demo plan (2 minutes): "The bad trade"

The story takes 1:30 at most. The last 30 seconds are for the evaluation and teacher report.

Whoever plays the learner says these lines exactly, so Pip's behavior is predictable on stage.

**Hook:** Pip traded 1/3 of a pizza for 1/4, because 4 is bigger than 3.
**Planned mistake (learner):** "It doesn't matter, you both get one slice, so it's the same."
**Fix the audience sees:** the 1/4 slice placed on top of the 1/3 slice, and it is clearly smaller.

## Part 1: the story (0:00 to 1:30)

| Time | Who | Line or action | What the screen shows |
|---|---|---|---|
| 0:00 | Presenter | "Most AI tutors explain things to kids. In TeachBack the AI is the student, and the kid has to teach it." | Empty whiteboard, Pip |
| 0:10 | Pip | "I traded my one third of the pizza for my friend's one fourth, because four is bigger than three. Did I get a good deal?" | |
| 0:20 | Learner (voice) | "It doesn't matter. You both get one slice, so it's the same." | |
| 0:25 | Pip | "Can you show me? I'll draw the pizzas." | Two same-size pizzas, one cut in 3, one cut in 4 |
| 0:32 | Learner (pen + voice) | Circles one slice in each pizza by hand. "See, one slice and one slice." | Hand-drawn circles around two slices |
| 0:40 | Pip | "I see you circled one slice in each pizza. But they don't look the same size. Let me put one on top of the other." | The 1/4 slice on top of the 1/3 slice, visibly smaller |
| 0:53 | Learner (voice) | "Oh! The third is bigger. Same size pizzas, so more slices means each slice is smaller." | |
| 1:05 | Pip | "So I gave away the bigger slice! I want my pizza back." | |
| 1:13 | | 17 seconds of slack for voice delays | |

The story has four Pip turns, so the slack covers about 4 seconds of delay per turn.

## Part 2: evaluation and teacher report (1:30 to 2:00)

| Time | Who | Line | What the screen shows |
|---|---|---|---|
| 1:30 | Presenter | "Now the teacher's view. It caught the misconception in the student's own words, 'you both get one slice, so it's the same', and shows the student fixed it themselves." | Teacher report: misconceptions card |
| 1:43 | Presenter | "Ideas explained went from zero to two out of three, and it tells the teacher what to do tomorrow." | Numbers row, then what to do next |
| 1:53 | Presenter | "TeachBack measures what kids can explain, not just whether they listened." | |

## What each part must deliver

- **Voice:** Pip's four lines are short, and the reply starts within about a second.
- **Whiteboard:** two pizzas of equal size cut into 3 and 4 equal slices, a freehand pen, and the one-slice-on-top-of-the-other comparison. Bars work too if circles are not ready; the lines stay the same with "bar" and "piece".
- **Vision:** at 0:40 Pip names what the learner circled. This is the proof the AI saw the drawing.
- **Evaluation and report:** the evaluator must finish during Pip's last line, so the report is ready at 1:30. Start it the moment the learner finishes the 0:53 line, or have a button that ends the session.

## Backup

- If voice fails, the learner types the same lines.
- If vision is not reliable by rehearsal, switch to tap to mark: the learner clicks a slice in each pizza and the app marks it. Pip says "I see you picked one slice in each pizza" and the rest is unchanged.
- If the live report is slow or fails, open the sample report and say it is a sample.
- No transfer challenge in the demo. If there is time before demos, run 1/6 versus 1/8 once for real and mention it in one sentence.
